# MindEase Figma Prototype Export

This directory contains the original, raw export generated by **Figma Make** (`-BT148--AI-Stress-Management-App-PWA`).

### Overview:
* **Source**: Figma Make
* **Architecture**: Next.js 16 (React 19), Tailwind CSS v4, Payload CMS, Lucide Icons
* **Active Integration**: The visual designs, screens, and CSS tokens from this export are converted into the active PWA in `/frontend/` and wired to the FastAPI backend.
